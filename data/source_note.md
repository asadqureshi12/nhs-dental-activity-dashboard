# Data Source

**Dataset:** NHS Dental Statistics for England — 2024/25  
**Publisher:** NHS Business Services Authority (NHS BSA)  
**URL:** https://www.nhsbsa.nhs.uk/statistical-collections/dental-england/dental-statistics-england-202425  
**Accessed:** March 2026  

## Notes
- Raw data downloaded as-is and saved as dtable_raw
- Data cleaned and standardised using cleaning_the_data.sql to produce dtable_cleaned
- Raw and cleaned datasets are not included in this repository due to NHS BSA data redistribution terms
- All analysis was performed on the cleaned dataset only
